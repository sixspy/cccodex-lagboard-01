# 迟到分级说明（锁定册）

> 本册为 `源到达SLA` 迟到分级的唯一口径，落库于 `data/app.db` 的 `grade_rules` 表。
> 选定即锁定：**当天不许改口**；任何改口或偏离请求一律拒绝，并记入 `grade_deviations`（`分级偏了`）。

## 一、互斥路径选择

迟到分级互斥落库写法只允许二选一，甲乙不得混用。本仓选定 **甲路径**。

| 路径 | 写法 | 事务边界 |
|------|------|----------|
| **甲（已选）** | 到达行与源输出态**同一事务**改写；失败则整笔回退，禁止半截成功 | 单事务：`INSERT arrivals` + `UPDATE sources.output_mode` + 回读校验，任一失败 `ROLLBACK` |
| 乙（未选） | 先落入影子到达表核对时限档，再原子晋升正式并改源输出态；中途失败影子作废、正式侧零写入 | 不使用 |

`grade_rules.path = '甲'`，`locked = 1`，`rule_day` 为锁定当日。运行期所有迟到写请求都校验该路径；
任何请求携带非 `甲` 的路径、或试图改册，均返回 `409 / code=分级偏了` 并落偏差记录。

## 二、迟到分钟 → 时限档（唯一分级函数）

设源时限为 `SLA` 分钟、迟到为 `lag` 分钟：

| 迟到分钟 | 时限档 | 源输出态 |
|----------|--------|----------|
| `lag <= SLA` | 正常 | 可写 |
| `SLA < lag <= 2*SLA` | 告警 | 降级只读 |
| `lag > 2*SLA` | 违约 | 冻结 |

分级只由迟到分钟推出，**不得**由页面、请求体或既有输出态反推。请求体若自带与推算不符的等级，
返回 `409 / 分级偏了` 并落偏差记录。

## 三、写路径硬约束

1. 到达行与源输出态同一事务改写，失败整笔回退（`503 / code=整笔回退 / rolled_back=true`）。
2. 分级写库成功后必须回读源输出态，回读不一致按失败处理并回退。
3. 禁止只改页面展示分级；禁止分级落库成功而源输出态仍旧。
4. 同一源到达（source + source_clock + ingest_clock）并发抢交须排队：先到者落库，
   后到者不写业务数据，只记 **迟到分级争用**（`contention` 表），返回 `409 / code=迟到分级争用`。
5. 补齐恢复：同一事务将源输出态恢复为「可写」并记录补齐基线 `restored_after_arrival_id`。

## 四、五处读数一致

以下五处均由同一库同一分级函数派生，必须对得上：

| 读数 | 接口 |
|------|------|
| 源目录 | `GET /api/sources` |
| 到达列表 | `GET /api/arrivals` |
| 迟到详情 | `GET /api/late`、`GET /api/late/{id}` |
| 补采附页 | `GET /api/catchups` |
| 水位卡片 | `GET /api/watermark` |

对账：`GET /api/reconcile`。返回 `consistent` 与 `mismatches`；任一到达等级与迟到分钟不符、
或源输出态与时限档/补齐恢复态不符，即判 `consistent=false`。

## 五、锁定信息

- 路径：**甲**
- `rule_day`：写入当日（见 `GET /api/rules`）
- `lock_sha`：路径 + 当日 + 分级口径的 SHA-256，写入 `grade_rules.lock_sha`
- 偏差记录：`GET /api/deviations`，`kind` 固定为 `分级偏了`
- 争用记录：`GET /api/contention`
